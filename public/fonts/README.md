Quiet Reader font assets

Upload these Gotham Pro TrueType files into this folder:

- GothamPro-Regular.ttf (weight 400)
- GothamPro-Medium.ttf (weight 500)
- GothamPro-Bold.ttf (weight 700)
- GothamPro-Light.ttf (weight 300)

The app registers them automatically in src/styles/tokens.css. Missing weights fall back to the closest available face and then to Inter/system sans-serif. Only add fonts you are licensed to redistribute.
